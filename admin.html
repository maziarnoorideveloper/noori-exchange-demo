نکته فنی:Technical note: این پنل داده‌ها را در حافظه‌ی محلی همین مرورگر (localStorage) ذخیره می‌کند، پس لندینگ پیج باید روی همین مرورگر/دستگاه باز شود تا تغییرات را ببیند. برای استفاده‌ی واقعی و نمایش به همه‌ی مشتریان روی اینترنت، لازم است این پنل به یک سرور و دیتابیس واقعی وصل شود — بخش NooriData در ابتدای همین فایل جایی است که این اتصال باید انجام شود. This panel stores data in this browser's local storage (localStorage), so the landing page must be opened on the same browser/device to see changes. For real use with actual customers online, this panel needs to be connected to a real server and database — the NooriData block at the top of this file is where that connection should be made.

This version is for portfolio demonstration and isn't yet connected to a real username/password login — in the final version, this panel sits behind secure login (JWT + hashed password) and no visitor can reach it without signing in.
